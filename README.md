# Project-Team-2

팀 프로젝트의 초기 디렉터리 구조입니다.

## 폴더 구조

```text
Project-Team-2/
├── .env                 # 환경변수 (Git 제외)
├── .env.example         # 환경변수 예시 템플릿
├── README.md            # 프로젝트 설명서
└── src/                 # 소스코드 최상위 폴더
    ├── feature/         # 피처(Feature) 생성 및 가공 관련 기능(함수)을 구현할 폴더
    └── tools/           # 공통 도구(Tools) 및 유틸리티 기능(함수)을 구현할 폴더
```

## 디렉터리 및 파일 설명

- `.env`: API 키 등 외부에 공개하면 안 되는 로컬 환경변수를 관리합니다. Git에는 포함되지 않습니다.
- `.env.example`: 프로젝트 실행에 필요한 환경변수 항목을 예시 값과 함께 공유합니다.
- `README.md`: 프로젝트 개요, 설정 방법, 실행 방법 등을 기록합니다.
- `src/feature/`: 피처 생성 및 가공과 관련된 기능과 함수를 구현합니다.
- `src/tools/`: 여러 기능에서 공통으로 사용하는 도구와 유틸리티 함수를 구현합니다.

## 시작하기

저장소를 내려받은 뒤 `.env.example`을 참고하여 `.env`에 필요한 환경변수를 설정합니다.

> 실제 API 키, 비밀번호 등 민감한 값은 `.env.example`이나 소스코드에 작성하지 마세요.
