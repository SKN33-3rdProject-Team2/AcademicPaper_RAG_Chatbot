# Toward Interpretable Music Tagging with Self-Attention 요약본

## 1. 연구 배경 및 목적

### 연구 배경

자동 음악 태깅은 오디오의 장르, 분위기, 악기, 보컬 유무 등 여러 태그를 동시에 예측하는 다중 레이블 분류 문제이다. 기존 MIR 연구에서는 주로 CNN과 RNN을 결합하거나, 깊은 CNN을 이용해 스펙트로그램의 시간–주파수 패턴을 학습해 왔다.

- **CNN 기반 모델**은 음색, 음높이, 화음과 같은 국소적 특징을 포착하는 데 강점이 있다.
- **RNN 기반 모델**은 시간적 순서를 모델링할 수 있지만, 긴 시퀀스에서는 계산량 증가와 그래디언트 소실·폭발 문제가 발생할 수 있다.
- **깊은 CNN 백엔드**는 넓은 시간 수용 영역을 확보할 수 있으나, 반복적인 풀링과 서브샘플링으로 인해 시간 해상도가 저하된다.
- 기존의 스펙트로그램 기반 2D CNN은 시간과 주파수 방향의 국소 패턴을 학습하는 데 집중하므로, 음악을 개별 오디오 이벤트의 연속적인 시퀀스로 해석하기 어렵고 모델의 판단 근거도 충분히 설명하기 어렵다.

음악의 의미는 단일 순간의 특징만으로 결정되지 않고, 시간적으로 멀리 떨어진 음향 사건들의 관계와 조합을 통해 형성된다. 예를 들어 특정 악기나 장르를 판단하려면 짧은 음색 정보뿐 아니라 반복되는 리듬, 선율, 화성 진행, 보컬 패턴 등을 종합해야 한다.

### 연구 목적

본 연구의 목적은 다음과 같다.

1. **자기 주의집중(self-attention)을 활용해 음악의 장기 시간 문맥을 모델링**한다.
2. CNN 프런트엔드가 추출한 국소 오디오 특징을 자기 주의집중 백엔드가 서로 연관시켜 고차원 음악 표현을 학습하도록 한다.
3. 기존 CNN 또는 CRNN 수준의 **경쟁력 있는 태깅 성능**을 유지한다.
4. 주의집중 맵과 태그별 기여도 맵을 통해 모델이 어떤 시간 구간을 활용했는지 시각화하여 **해석 가능성을 향상**한다.

즉, 이 논문은 단순히 성능을 높이는 것뿐 아니라, “모델이 음악의 어느 부분을 보고 특정 태그를 예측했는가?”라는 질문에 답할 수 있는 음악 태깅 구조를 제안한다.

## 2. 핵심 방법론 및 아키텍처

### 2.1 전체 구조: CNN 프런트엔드 + 자기 주의집중 백엔드

제안 모델은 음악 오디오를 먼저 CNN으로 처리한 뒤, 그 결과를 시간축을 갖는 시퀀스로 변환하여 트랜스포머 인코더 형태의 자기 주의집중 백엔드에 입력한다.

\[
\text{오디오 입력}
\rightarrow
\text{CNN 프런트엔드}
\rightarrow
\text{시간적 특징 시퀀스}
\rightarrow
\text{다중 헤드 자기 주의집중}
\rightarrow
\text{태그 예측}
\]

모델은 프런트엔드 입력 유형에 따라 두 가지로 구성된다.

- **Spec Att**: 로그 멜 스펙트로그램 기반 2D CNN + 자기 주의집중 백엔드
- **Raw Att**: 원시 파형 기반 1D CNN + 자기 주의집중 백엔드

비교 기준선으로는 다음 모델들이 사용되었다.

- **Spec–\(CNN_P\)**: 스펙트로그램 CNN 프런트엔드 + CNN 백엔드
- **Raw–\(CNN_L\)**: 원시 파형 CNN 기반 기준선
- 제안 모델: **Spec Att**, **Raw Att**

---

### 2.2 스펙트로그램 프런트엔드

스펙트로그램 프런트엔드는 음악적으로 의미 있는 두 종류의 정보를 분리하여 추출하도록 설계되었다.

#### 세로 필터

세로 방향의 필터는 여러 주파수 대역에 걸친 구조를 관찰하여 음색 관련 정보를 포착한다. 합성곱 결과는 주파수축 평균 풀링을 거치며, 이를 통해 주파수 위치 정보는 줄이고 시간적 변화는 보존한다.

이 과정은 다음과 같은 특징을 학습하는 데 유리하다.

- 악기 음색
- 음색의 주파수 구조
- 특정 소리의 스펙트럼 특성

#### 가로 필터

가로 방향의 필터는 시간축의 변화를 포착한다. 주파수축으로 평균 풀링된 특징에 적용되어 다음과 같은 정보를 모델링한다.

- 시간적 플럭스
- 리듬과 반복 패턴
- 짧은 시간 내 음향 변화

입력은 16kHz 오디오에서 약 4.1초에 해당하는 256개 스펙트로그램 프레임이다. 로그 멜 스펙트로그램은 512 샘플 해닝 창, 50% 중첩, 96개 멜 빈을 사용해 생성되었다.

---

### 2.3 원시 오디오 프런트엔드

Raw 프런트엔드는 STFT나 멜 스펙트로그램 변환 없이 원시 파형을 직접 처리하는 1D CNN이다.

- 약 65,610개 샘플
- 16kHz 기준 약 4.1초 오디오
- 짧은 1D 합성곱 필터를 여러 층 적용
- 약 15.2ms의 오디오를 포함하는 시간 프레임 단위 특징 생성

자기 주의집중 백엔드와의 공정한 비교를 위해 Raw 프런트엔드 뒤에는 \(1 \times 7\) 합성곱 층을 추가하였다. 이는 Spec 프런트엔드의 세로 필터가 최대 7개 시간 프레임, 약 112ms 범위의 정보를 포괄하는 것에 대응하기 위한 것이다.

---

### 2.4 자기 주의집중 백엔드

CNN의 출력은 시간축을 따라 정렬된 특징 벡터 시퀀스로 해석된다. 예를 들어 Raw 특징을 다음과 같이 나타낼 수 있다.

\[
X \in \mathbb{R}^{T \times C}
\]

여기서 \(T\)는 시간 단계의 수이고, \(C\)는 각 시간 단계의 특징 차원이다. 각 시간 단계의 특징 벡터를 NLP에서의 단어 임베딩과 유사한 시퀀스 요소로 간주한다.

입력 특징으로부터 질의, 키, 값을 생성한다.

\[
Q=XW_{\theta}, \qquad
K=XW_{\phi}, \qquad
V=XW_g
\]

그 후 스케일 조정 내적 주의집중을 계산한다.

\[
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
\]

이 구조에서 각 시간 구간은 다른 모든 시간 구간과 직접적인 관계를 맺을 수 있다. 따라서 CNN의 국소 특징을 다음과 같은 장기 구조로 결합할 수 있다.

- 반복되는 리듬 패턴
- 선율 윤곽
- 화음 진행
- 보컬 또는 악기의 반복적 등장
- 장르적·분위기적 특성을 구성하는 여러 음향 사건의 관계

분류 과제이므로 트랜스포머의 전체 인코더–디코더 구조가 아니라 **인코더 부분만 사용**하였다. 또한 BERT와 유사하게 전체 시퀀스 정보를 집약하는 \([CLS]\) 토큰을 두고, 이를 최종 태그 분류에 활용한다. 자기 주의집중 층은 다중 헤드 방식으로 구성되며, 절제 실험 결과 최종 설정은 다음과 같다.

- 자기 주의집중 층: 2개
- 주의집중 헤드: 8개

### 2.5 혼합 최적화 전략

학습에는 Adam과 SGD를 결합한 별도의 최적화 전략을 사용하였다.

1. 초기 60에포크:
   - Adam 사용
   - 빠른 수렴 유도
   - 학습률 \(10^{-4}\)
2. 60에포크 이후:
   - 검증 AUROC가 가장 높았던 가중치로 복원
   - 모멘텀 0.9와 네스테로프 모멘텀을 사용하는 SGD로 전환
3. 80에포크와 100에포크:
   - 학습률을 각각 10% 감소

Adam은 초기 학습 속도가 빠르지만 후반부 일반화 성능이 저하될 수 있다는 점에 착안한 방식이다. 가장 좋은 모델 가중치를 불러온 뒤 SGD로 전환함으로써 Adam의 빠른 수렴과 SGD의 일반화 특성을 결합하고자 했다.

### 2.6 해석 가능성 시각화

논문은 두 가지 유형의 시각화를 제안한다.

#### 주의집중 히트맵

각 주의집중 헤드의 점수를 합산하여, 모델이 오디오의 어느 시간 구간에 집중했는지 보여준다.

이를 통해 다음을 관찰할 수 있다.

- 모델이 오디오 이벤트가 존재하는 부분에 강하게 반응
- 비트, 여성 보컬 등 관련 음향 사건이 있는 구간에 집중
- 특정 태그와 관련된 시간 영역을 대략적으로 확인 가능

그러나 주의집중 히트맵만으로는 “왜 그 구간이 해당 태그의 증거가 되었는가”까지는 설명하지 못한다.

#### 태그별 기여도 히트맵

특정 태그의 기여도를 보기 위해 마지막 주의집중 층의 가중치를 시간 단계별로 수동 조작한다. 한 시간 단계만 활성화하고 나머지를 제거한 뒤 태그 출력의 변화를 관찰함으로써, 각 태그가 어떤 시간 구간에 의존하는지 확인한다.

예를 들어 피아노와 플루트가 연결된 스펙트로그램을 입력하면 다음을 분리하여 확인할 수 있다.

- 피아노 태그는 피아노가 등장하는 구간에 주로 반응
- 플루트 태그는 플루트가 등장하는 구간에 주로 반응
- “조용함”과 “시끄러움”처럼 서로 대비되는 분위기 태그도 서로 다른 구간에 기여

이 방식은 단순한 주의집중 시각화보다 태그별 판단 근거를 더 구체적으로 보여준다.

## 3. 주요 실험 성과

### 3.1 데이터셋과 평가 지표

실험에는 두 개의 음악 태깅 데이터셋이 사용되었다.

- **MagnaTagATune(MTAT)**
  - 약 26,000개 오디오 클립
  - 상위 50개 태그 사용
  - 태그가 전혀 없는 클립을 제거한 약 21,000개 부분집합 사용
- **Million Song Dataset(MSD)**
  - 약 242,000곡
  - Last.FM 상위 50개 태그 사용
  - 29.1초보다 짧은 곡 제거

평가 지표는 다음과 같다.

- **AUROC**: ROC 곡선 아래 면적
- **AUPR**: 정밀도–재현율 곡선 아래 면적

사용자 생성 태그는 태그별 빈도 차이가 크고 데이터 불균형이 심하기 때문에, 논문은 AUROC뿐 아니라 AUPR도 함께 보고했다.

---

### 3.2 정량적 성능

MTAT에서의 핵심 결과는 다음과 같다.

| 모델 | AUROC | AUPR |
|---|---:|---:|
| Raw–\(CNN_L\) 기준선 | 90.62 | 44.20 |
| Raw Att | **90.66** | **44.21** |
| Spec–\(CNN_P\) 기준선 | **90.89** | **45.03** |
| Spec Att | 90.80 | 44.39 |

주요 해석은 다음과 같다.

1. **Raw Att는 Raw CNN 기준선과 사실상 동등한 성능**을 달성했다.
   - AUROC: 90.62 → 90.66
   - AUPR: 44.20 → 44.21
2. **Spec Att는 성능 면에서 CNN 기준선에 근접**했다.
   - AUROC: 90.80
   - AUPR: 44.39
3. 스펙트로그램 기준선인 Spec–\(CNN_P\)가 수치상 가장 높았지만, 제안 모델은 약간 낮은 성능으로도 자기 주의집중 기반 구조의 가능성을 보여주었다.
4. 따라서 자기 주의집중 백엔드는 기존 CNN 백엔드를 완전히 압도하지는 않았지만, **성능을 크게 희생하지 않으면서 장기 문맥 모델링과 시각적 해석을 제공**했다.

제공된 표에서는 MSD의 구체적인 AUROC와 AUPR 수치가 제시되지 않았으므로, MSD에 대해 수치상 우월성을 단정할 수는 없다. 다만 논문은 MTAT와 MSD 모두에서 제안 Att 백엔드가 경쟁력 있는 결과를 보였다고 보고한다.

---

### 3.3 주의집중 헤드와 층에 대한 절제 실험

MTAT에서 주의집중 구조의 규모를 바꾼 결과는 다음과 같다.

- 1개 헤드, 1개 층:
  - AUROC 87.73
  - AUPR 36.93
- 8개 헤드, 1개 층:
  - AUROC 90.40
  - AUPR 43.89
- 8개 헤드, 2개 층:
  - AUROC 90.80
  - AUPR 44.39
- 8개 헤드, 3개 층:
  - AUROC 90.54
  - AUPR 44.12

이에 따라 다음과 같은 결론을 얻었다.

- 헤드 수를 1개에서 8개로 늘리면 성능이 크게 개선된다.
- 자기 주의집중 층을 1개에서 2개로 늘리면 추가 개선이 나타난다.
- 2개를 초과해 층을 쌓아도 성능이 향상되지 않으며, 오히려 3개 층에서는 소폭 하락한다.
- 약 4.1초 입력에 대해서는 **8헤드·2층 설정이 가장 적절**하다.

이는 단순히 자기 주의집중 층을 많이 쌓는 것이 항상 유리한 것은 아니며, 입력 길이와 모델 규모의 균형이 중요함을 보여준다.

---

### 3.4 최적화 실험

Adam, SGD, 제안한 혼합 최적화 방법을 비교한 결과는 다음과 같다.

- Adam:
  - 초기 수렴이 빠름
  - 약 100에포크 이후 AUROC와 AUPR이 하락
  - 과적합 또는 일반화 저하 발생
- SGD:
  - 초기 학습 속도는 상대적으로 느림
  - 일반화 측면에서 안정적
- 제안 방식:
  - 초기에는 Adam처럼 빠르게 학습
  - 이후 SGD로 전환하여 안정적인 일반화 성능 유지

따라서 이 연구의 최적화 전략은 성능 자체뿐 아니라 학습 안정성을 개선하는 실용적인 구성으로 평가된다.

---

### 3.5 긴 시퀀스 실험

기본 실험에서는 공정한 비교를 위해 약 4.1초의 오디오만 사용했다. 이후 Spec Att에 약 16.4초에 해당하는 1024개 프레임을 입력하여 장기 문맥 능력을 별도로 평가했다.

| 입력 길이 | 층 수 | AUROC | AUPR |
|---:|---:|---:|---:|
| 256 | 2 | 90.80 | 44.39 |
| 1024 | 2 | 89.62 | 41.61 |
| 1024 | 4 | 89.85 | 42.25 |
| 1024 | 6 | 89.86 | 41.84 |

긴 입력에서는 성능이 다소 낮아졌다. 층 수를 2개에서 4개, 6개로 늘려도 4.1초 입력의 성능을 회복하지 못했다.

이는 자기 주의집중이 장기 의존성을 표현할 수 있는 구조이기는 하지만, 단순히 입력 길이를 늘리는 것만으로 성능이 개선되지는 않음을 의미한다. 긴 시퀀스에서는 다음 문제가 발생한다.

- 자기 주의집중의 계산량과 메모리 사용량이 시퀀스 길이에 대해 제곱으로 증가
- 긴 입력에 맞는 충분한 모델 용량과 학습 전략 필요
- 장기 정보가 실제 태그 예측에 유용한지에 대한 추가적인 설계 필요

---

### 3.6 태그별 성능과 시각화 결과

태그별 AUROC에서는 악기와 장르 태그가 대체로 높은 성능을 보였다.

높은 성능을 보인 예시는 다음과 같다.

- metal: 98.79
- choral: 98.68
- choir: 98.65
- rock: 98.52
- opera: 98.34
- flute: 97.91
- piano: 95.69

반면 부정적 또는 부재를 나타내는 태그는 취약했다.

- no vocal: 71.86
- no vocals: 70.22
- no voice: 67.88

“조용함”과 “보컬 없음”과 같은 태그에서 모델은 실제로 해당 특성이 없는 구간보다 소리나 이벤트가 존재하는 구간에 주의를 기울이는 경향을 보였다. 이는 모델이 부재 자체를 탐지하기보다, 상대적으로 정보량이 높은 음향 구간을 이용해 간접적으로 태그를 판단하기 때문일 가능성이 있다.

## 4. 연구의 시사점 및 한계점

### 4.1 연구의 주요 시사점

#### 첫째, 음악을 시퀀스로 다루는 구조의 타당성을 제시했다

이 연구의 가장 중요한 기여는 음악 오디오를 단순한 2D 시간–주파수 이미지로만 처리하지 않고, CNN이 추출한 시간별 특징의 시퀀스로 해석했다는 점이다.

- CNN 프런트엔드: 국소적 음향 사건 추출
- 자기 주의집중 백엔드: 서로 멀리 떨어진 사건 간 관계 모델링

이는 음악의 계층적 구조, 반복성, 장기적 문맥을 모델링하는 데 적합한 관점이다.

#### 둘째, 성능과 해석 가능성 사이의 절충안을 제시했다

Spec Att와 Raw Att는 당시의 CNN 기준선보다 명확히 우수하지는 않았지만, 성능이 거의 동등한 수준을 유지했다. 그 대신 기존 CNN보다 모델이 어느 시간 구간을 참조했는지 직접 시각화할 수 있었다.

따라서 이 연구의 핵심 성과는 단순한 최고 성능 갱신이라기보다 다음과 같은 균형에 있다.

> 경쟁력 있는 분류 성능 + 시간 구간 단위의 판단 과정 시각화

#### 셋째, 태그별 설명 가능성의 필요성을 보여주었다

전체 주의집중 맵은 모델이 관심을 둔 부분을 보여주지만, 특정 태그의 판단 근거를 충분히 분리하지 못한다. 논문은 태그별 기여도 히트맵을 통해 이 문제를 보완했다.

이 방식은 향후 다음과 같은 응용에 활용될 수 있다.

- 음악 추천 시스템의 태그 근거 제시
- 음악 검색 결과의 설명
- 잘못된 태그 예측의 원인 분석
- 데이터셋 라벨 오류 탐지
- 음악가·음악 연구자를 위한 모델 행동 분석

#### 넷째, 자기 주의집중의 분석 도구로서 가능성을 보여주었다

주의집중 시각화는 단순한 설명 도구일 뿐 아니라, 모델이 어떤 음향 사건을 태그와 연결하는지 분석하는 연구 도구가 될 수 있다. 예를 들어 장르, 악기, 분위기 태그가 실제로 어떤 시간적·음향적 패턴과 연결되는지를 탐색할 수 있다.

#### 다섯째, 다양한 MIR 과제로의 확장 가능성이 있다

제안된 CNN–자기 주의집중 구조는 음악 태깅에만 한정되지 않는다. 논문은 다음 과제로 확장할 수 있다고 제안한다.

- 박자 및 다운비트 검출
- 리듬 분류
- 음악 전사
- 장기 음악 구조 분석
- 악기 및 보컬 활동 분석

### 4.2 연구의 한계점

#### 첫째, 주의집중이 곧 완전한 설명은 아니다

논문도 인정하듯이 주의집중 히트맵은 모델이 “어디를 보았는가”를 보여줄 뿐, 반드시 “왜 그 태그를 예측했는가”를 정확하게 설명하지는 않는다.

특히 다음과 같은 문제가 있다.

- 주의집중이 실제 결정에 인과적으로 기여했는지 불분명
- 높은 주의집중이 높은 예측 기여도를 항상 의미하지 않음
- 여러 층과 헤드의 주의집중을 합산하면 세부 구조가 사라짐
- 태그별 기여도 조작 방식이 모델의 자연스러운 추론을 직접 반영하지 않을 가능성

따라서 향후에는 입력 삭제 실험, 기울기 기반 분석, 섭동 실험, 대체 설명 모델 등과 비교하여 설명의 충실성을 검증할 필요가 있다.

#### 둘째, 최고 성능 모델을 능가하지는 못했다

MTAT에서 Spec–\(CNN_P\) 기준선은 다음과 같이 제안 모델보다 약간 우수했다.

- 기준선: AUROC 90.89, AUPR 45.03
- Spec Att: AUROC 90.80, AUPR 44.39

즉 자기 주의집중 도입이 성능 향상으로 직접 이어진 것은 아니다. 이 연구의 기여는 주로 해석 가능성과 장기 문맥 모델링의 잠재력에 있으며, 순수한 분류 정확도 측면에서는 CNN 기준선과 경쟁하는 수준이다.

#### 셋째, 긴 시퀀스에서 계산 복잡도가 크다

자기 주의집중은 모든 시간 위치 쌍을 비교하므로 시퀀스 길이 \(T\)에 대해 대략 \(O(T^2)\)의 계산 및 메모리 비용이 발생한다.

이 때문에 약 4.1초 입력에서는 작동하지만, 16.4초 입력에서는 다음 문제가 나타났다.

- 메모리 부담 증가
- 입력 길이 증가에 따른 성능 저하
- 더 많은 주의집중 층을 쌓아도 성능 개선 제한

논문은 국소 자기 주의집중이나 근사형 비국소 연산을 대안으로 제시하지만, 해당 방법들을 실제 음악 태깅에 적용한 결과는 제시하지 않았다.

#### 넷째, 입력 길이와 모델 설정이 제한적이다

주요 실험은 약 4.1초의 짧은 오디오 청크를 중심으로 수행되었다. 따라서 다음과 같은 음악적 장기 구조를 충분히 반영하지 못할 수 있다.

- 곡 전체의 형식 구조
- 절과 후렴의 반복 관계
- 장시간에 걸친 화성 진행
- 곡 전체의 분위기 변화
- 도입부와 클라이맥스의 관계

또한 16.4초 실험만으로 훨씬 긴 음악 시퀀스에 대한 확장성을 판단하기는 어렵다.

#### 다섯째, 태그 불균형과 부정적 태그에 취약하다

MTAT와 MSD는 사용자 생성 태그에 기반하기 때문에 인기도 편향과 심한 클래스 불균형을 갖는다. AUROC는 상대적으로 높게 나타날 수 있지만, 실제 희소 태그 검색 성능을 충분히 반영하지 못할 수 있다. 이러한 이유로 AUPR을 함께 사용했으나, 부정적 태그에서는 성능이 상당히 낮았다.

특히 “no voice”, “no vocals”, “no vocal”은 모델이 음성의 부재를 직접 학습하기보다 정보량이 높은 음향 구간에 의존하는 문제를 드러낸다. 이는 태그 의미가 존재 기반인지 부재 기반인지에 따라 별도의 학습 전략이 필요함을 시사한다.

#### 여섯째, 실험 규모와 비교 범위가 제한적이다

논문은 당시 대표적인 CNN·Raw 모델과 비교했지만, 다음과 같은 비교는 충분히 이루어지지 않았다.

- 더 깊거나 대규모 트랜스포머
- 계층적 자기 주의집중
- 국소·희소 주의집중
- 사전 학습된 음악 표현 모델
- 현대적인 설명 가능성 기법과의 정량적 비교
- 설명의 인간 평가 또는 사용자 연구

따라서 제안 모델의 해석 가능성이 실제 사용자에게 얼마나 유용한지, 그리고 다른 설명 기법보다 우수한지는 추가 검증이 필요하다.

### 종합 평가

이 논문은 음악 태깅에서 CNN의 국소 표현 능력과 자기 주의집중의 장기 문맥 모델링 능력을 결합한 초기 연구로서 의미가 크다. 제안 모델은 기존 CNN 기준선을 압도하지는 않았지만, 유사한 성능을 유지하면서 모델의 시간적 관심 영역과 태그별 기여도를 시각화할 수 있음을 보였다.

핵심적인 연구 메시지는 다음과 같이 요약할 수 있다.

> 음악 태깅 모델은 단순히 높은 예측 성능을 내는 것에서 나아가, 음악의 어떤 시간적 사건들이 특정 태그의 판단에 기여했는지를 설명할 수 있어야 한다. CNN–자기 주의집중 구조는 이러한 성능과 해석 가능성의 균형을 탐색하는 유망한 출발점이지만, 긴 시퀀스의 계산 비용과 주의집중 설명의 충실성 문제는 향후 해결해야 할 과제이다.
