# Self-Attention as Distributional Projection: A Unified Interpretation of Transformer Architecture 요약본

## 1. 연구 배경 및 목적

### 연구 배경

본 논문은 트랜스포머의 자기 어텐션을 일반적으로 사용되는 “쿼리가 키를 검색하고 값을 가져오는 과정”으로 설명하는 방식에 문제를 제기한다. 저자는 실제 연산이 검색 절차라기보다 학습된 선형 변환과 행렬 연산으로 구성되어 있으므로, 정보 검색 비유만으로는 다음과 같은 핵심 질문에 충분히 답하기 어렵다고 본다.

- 왜 어텐션 점수는 쿼리와 키의 내적으로 계산되는가?
- 왜 쿼리와 키는 분리된 선형 사영을 사용하는가?
- 위치 인코딩과 다중 헤드 어텐션은 어떤 원리에서 비롯되는가?
- 자기 어텐션은 고전적인 분포 의미론이나 공기 통계와 어떤 관계를 갖는가?

이를 해결하기 위해 논문은 GloVe와 같은 분포 의미론의 핵심 개념인 **공기(co-occurrence) 통계**에서 출발한다. 단어의 의미가 그 단어가 어떤 문맥에서 함께 등장하는지에 의해 형성된다는 관점에서, 전역 공기 행렬을 현재 입력 시퀀스의 문맥으로 제한하고, 이를 자기 어텐션의 수학적 기반으로 해석한다.

### 연구 목적

논문의 중심 목적은 트랜스포머의 자기 어텐션을 다음과 같은 단계적 확장으로 통합적으로 설명하는 것이다.

\[
S
\rightarrow QSQ^\top
\rightarrow QW_QW_K^\top Q^\top
\rightarrow (Q+P)S(Q+P)^\top
\rightarrow
\operatorname{softmax}\left(\frac{HW_QW_K^\top H^\top}{\sqrt{d_k}}\right)(HW_V)
\]

여기서 각 단계는 다음을 의미한다.

1. **전역 공기 구조 \(S\)**: 말뭉치 수준의 단어 간 연관성
2. **국소 사영 \(QSQ^\top\)**: 전역 통계를 현재 시퀀스 내부의 관계로 제한
3. **비대칭 사영 \(QW_QW_K^\top Q^\top\)**: 방향성 있는 언어 관계 모델링
4. **위치가 결합된 사영 \((Q+P)S(Q+P)^\top\)**: 순서 및 위치 정보 반영
5. **학습된 자기 어텐션**: 위 구조를 저차원·학습 가능한 형태로 일반화

따라서 본 논문은 트랜스포머의 구성 요소들이 임의적으로 결합된 설계가 아니라, 분포 의미론을 문맥적·방향성·순서 민감적 모델로 확장하는 과정에서 자연스럽게 도출된다고 주장한다.

## 2. 핵심 방법론 및 아키텍처

### 2.1 전역 공기 행렬에서 국소 문맥 사영으로

어휘 크기가 \(n\)인 말뭉치에서 전역 공기 행렬을 다음과 같이 정의한다.

\[
S\in\mathbb{R}^{n\times n}
\]

행렬의 원소 \(S_{ij}\)는 토큰 \(i\)와 \(j\) 사이의 경험적 연관성 또는 공기 정도를 나타낸다. 한 토큰의 원-핫 벡터에 \(S\)를 곱하면, 해당 토큰이 전체 어휘의 어떤 항목들과 함께 등장하는지에 관한 분포가 얻어진다.

입력 시퀀스 길이가 \(R\)이고, 선택 행렬 \(Q\in\mathbb{R}^{R\times n}\)가 시퀀스에 등장한 토큰을 선택한다고 하자. 그러면

\[
M=QSQ^\top
\]

은 전역 공기 구조를 현재 시퀀스에 존재하는 토큰들 사이의 관계로 제한한다.

- \(QS\): 입력 토큰에서 전체 어휘로 향하는 연관성
- \(Q^\top\): 입력 시퀀스에 포함된 토큰만 다시 선택
- \(QSQ^\top\): 현재 시퀀스 내부 토큰 간 문맥적 관계

즉, \(M_{rs}\)는 위치 \(r\)의 토큰과 위치 \(s\)의 토큰이 전역 분포 구조상 얼마나 연관되는지를 표현한다.

논문은 이 과정을 전역적인 언어 지식을 현재 문장에 맞게 조정하는 과정으로 해석한다. 여러 입력 토큰과 공통적으로 관련된 연관성은 강화되고, 특정 토큰 하나에만 국한된 연관성은 상대적으로 약화된다. 이 점에서 \(QSQ^\top\)는 원시적인 자기 어텐션 행렬로 간주된다.

### 2.2 정규화와 어텐션 가중치

논문은 \(M\)을 문맥적 확률 분포와 유사한 가중치로 바꾸기 위해 행별 정규화를 제안한다.

\[
\operatorname{Norm}(M)_{rs}
=
\frac{M_{rs}}{\sum_t M_{rt}}
\]

이때 각 행은 특정 토큰이 시퀀스 내 다른 토큰들에 부여하는 상대적 가중치로 해석된다. 개념적으로는 표준 자기 어텐션의 행별 소프트맥스와 대응한다.

다만 논문에서 사용하는 정규화는 일반적인 트랜스포머의 소프트맥스와 동일하지 않다. 표준 어텐션은 다음과 같이 정의된다.

\[
A=
\operatorname{softmax}
\left(
\frac{Q_{\mathrm{att}}K_{\mathrm{att}}^\top}{\sqrt{d_k}}
\right)
\]

소프트맥스는 음수 점수도 처리할 수 있고 항상 양의 확률 분포를 만들지만, 단순한 행 합 정규화는 \(M\)의 원소가 음수이거나 행 합이 0인 경우 정의되지 않을 수 있다. 따라서 이 부분은 자기 어텐션과의 개념적 유사성을 제시하는 수준으로 이해하는 것이 적절하다.

### 2.3 어휘 수준 예측으로의 확장

시퀀스 내부 관계 \(M\)을 전체 어휘 공간의 예측으로 확장하기 위해 다음 연산을 사용한다.

\[
E=M(QS)
=
(QSQ^\top)(QS)
\]

각 원소는 다음과 같이 표현된다.

\[
E_{rj}
=
\sum_{s=1}^{R}
M_{rs}(QS)_{sj}
\]

이는 위치 \(r\)의 토큰이 다른 위치 \(s\)의 토큰에 부여한 문맥 가중치를 이용하여, 전체 어휘 항목 \(j\)에 대한 증거를 재결합하는 과정이다.

논문의 해석에 따르면,

- 여러 토큰과 일관되게 연결된 어휘 항목은 높은 점수를 얻고,
- 단일 토큰과만 연결된 항목은 상대적으로 희석되며,
- 전체 시퀀스와 의미적으로 부합하는 항목이 다음 토큰 후보로 강화된다.

위치별 예측을 평균하여 전역 예측 벡터를 만들고, 여기에 소프트맥스를 적용한다.

\[
e_{\mathrm{global}}
=
\frac{1}{R}
\sum_{r=1}^{R}E_r
\]

\[
p(w_i\mid \mathrm{context})
=
\operatorname{softmax}
(e_{\mathrm{global}})_i
\]

이 구조는 자기 어텐션이 단순히 토큰 간 유사도를 계산하는 것이 아니라, 문맥적 상호작용을 이용해 어휘 수준의 예측 증거를 재구성한다는 점을 강조한다.

### 2.4 위치 인코딩의 도입

기본 사영 \(QSQ^\top\)은 토큰의 존재 여부만 반영하고 순서는 반영하지 못한다. 따라서 동일한 토큰 집합을 갖는 서로 다른 문장들을 구분하기 어렵다.

논문은 위치 행렬 \(P\)를 도입하여 선택 행렬을 다음과 같이 확장한다.

\[
Q'=Q+P
\]

그 결과 사영은

\[
M'
=
Q'S(Q')^\top
\]

가 되며, 전개하면

\[
M'
=
QSQ^\top
+
QSP^\top
+
PSQ^\top
+
PSP^\top
\]

이다.

각 항은 다음과 같이 해석된다.

- \(QSQ^\top\): 내용과 내용 사이의 상호작용
- \(QSP^\top\): 어휘 내용이 특정 위치와 어떻게 결합되는가
- \(PSQ^\top\): 위치적 역할이 어떤 어휘 내용을 선호하는가
- \(PSP^\top\): 위치와 위치 사이의 구조적 편향

이 설명의 핵심은 위치 인코딩을 별도의 부가 장치가 아니라, 사영의 입력 공간을 “토큰 정체성”에서 “토큰-위치 결합 표현”으로 확장하는 과정으로 보는 것이다.

### 2.5 쿼리-키 분리와 방향성

대칭적 공기 행렬 \(S\)와 \(QSQ^\top\)만으로는 방향성 있는 관계를 표현하기 어렵다. 예를 들어 주어와 목적어, 행위자와 대상, 원인과 결과는 단순한 대칭적 공기 관계와 다르다.

이를 위해 논문은 다음과 같은 학습된 사영을 도입한다.

\[
Q_{\mathrm{att}}=QW_Q,\qquad
K_{\mathrm{att}}=QW_K
\]

그리고 방향성 점수 행렬을

\[
M_{\mathrm{dir}}
=
Q_{\mathrm{att}}K_{\mathrm{att}}^\top
=
QW_QW_K^\top Q^\top
\]

로 정의한다.

\(W_QW_K^\top\)가 대칭일 필요가 없기 때문에 일반적으로

\[
(M_{\mathrm{dir}})_{rs}
\neq
(M_{\mathrm{dir}})_{sr}
\]

이다. 따라서 쿼리-키 분리는 “검색”을 구현하기 위한 장치라기보다, 대칭적 공기 구조를 비대칭적 관계 구조로 일반화하기 위한 수학적 장치로 해석된다.

### 2.6 값 사영과 표준 자기 어텐션

값 사영은

\[
V_{\mathrm{att}}=QW_V
\]

로 정의되며, 최종 출력은

\[
Y
=
\operatorname{softmax}
\left(
\frac{Q_{\mathrm{att}}K_{\mathrm{att}}^\top}{\sqrt{d_k}}
\right)
V_{\mathrm{att}}
\]

이다.

현재 트랜스포머 표현을 \(H\)로 쓰면 다음과 같다.

\[
Y
=
\operatorname{softmax}
\left(
\frac{HW_QW_K^\top H^\top}{\sqrt{d_k}}
\right)
(HW_V)
\]

논문은 이를 다음과 같이 해석한다.

- \(W_Q\): 각 토큰이 어떤 종류의 문맥을 질의하는지 결정
- \(W_K\): 각 토큰이 어떤 관계적 역할을 제공하는지 결정
- \(W_V\): 실제로 전달·혼합되는 내용 표현을 결정
- 소프트맥스: 방향성 점수를 확률적 가중치로 변환
- \(W_V\): 문맥적으로 선택된 정보를 새로운 표현 공간으로 전달

### 2.7 다중 헤드 및 교차 어텐션

다중 헤드 어텐션에서는 각 헤드가 별도의 \(W_Q^{(i)},W_K^{(i)},W_V^{(i)}\)를 사용한다.

\[
Y^{(i)}
=
\operatorname{softmax}
\left(
\frac{Q^{(i)}K^{(i)\top}}{\sqrt{d_k}}
\right)V^{(i)}
\]

각 헤드의 출력은 연결되고 \(W_O\)를 통해 재결합된다.

논문은 이를 하나의 공기 구조 \(S\)를 여러 개의 저차원 관계 구성 요소로 분해하는 것으로 해석한다. 각 헤드는 구문적 의존성, 상호참조, 주제적 응집성, 담화 관계 등 서로 다른 관계 패턴을 학습할 수 있다.

교차 어텐션은 쿼리와 키·값이 서로 다른 시퀀스에서 오는 경우로 일반화된다.

\[
Y_{\mathrm{cross}}
=
\operatorname{softmax}
\left(
\frac{H_{\mathrm{tgt}}W_Q
(H_{\mathrm{src}}W_K)^\top}{\sqrt{d_k}}
\right)
(H_{\mathrm{src}}W_V)
\]

이는 소스 시퀀스의 관계 구조를 타깃 시퀀스의 질의 공간에 비대칭적으로 사영하는 것으로 설명된다.

## 3. 주요 실험 성과

### 3.1 실험의 성격

이 논문은 전통적인 의미의 실증 연구나 벤치마크 연구가 아니다. 실제 대규모 말뭉치, 사전학습 트랜스포머, 표준 NLP 데이터셋을 이용한 성능 비교나 어텐션 헤드 분석 실험은 수행하지 않는다.

논문이 제시하는 근거는 주로 다음 세 가지다.

1. 선형대수적 도출
2. 소규모 개념 예시
3. 사영 연산의 유일성에 관한 형식적 명제

따라서 “주요 실험 성과”는 실제 모델의 성능 향상이라기보다, 제안한 해석 틀이 어떤 현상을 설명하는지를 보여주는 **이론적·개념적 검증**으로 이해해야 한다.

### 3.2 공기 사영의 개념적 검증

첫 번째 예시는 “river bank flooded”라는 지리적 문맥이다. 여기서 bank는 지리적 의미와 금융적 의미를 동시에 가질 수 있지만, river와 flooded가 함께 등장하면서 지리적 의미가 강화된다고 설명한다.

정규화된 관계 행렬은 다음과 같이 제시된다.

\[
\operatorname{Norm}(M)
=
\begin{bmatrix}
0.00&0.44&0.56\\
0.57&0.00&0.43\\
0.62&0.38&0.00
\end{bmatrix}
\]

논문은 이 결과를 통해 다음을 주장한다.

- river와 flooded가 bank의 지리적 의미를 지지한다.
- bank의 금융적 연관성은 현재 문맥의 다른 토큰들로부터 충분한 지지를 얻지 못한다.
- 따라서 문맥 사영이 다의성 해소 기능을 수행한다.

두 번째 예시인 “bank loan”에서는 bank와 loan의 금융적 연관성이 강하게 작용하여 bank의 금융적 의미가 선택된다고 설명한다.

이 두 사례의 핵심 성과는 동일한 토큰 bank가 주변 문맥에 따라 서로 다른 의미적 관계망에 배치된다는 점을 간단한 행렬 계산으로 보여준 것이다.

### 3.3 다음 토큰 예측의 개념적 예시

논문은

\[
E=(QSQ^\top)(QS)
\]

를 이용해 전체 어휘에 대한 예측 점수를 산출한다.

- “river bank flooded”에서는 shore가 높은 점수를 얻고,
- “bank loan”에서는 money가 높은 점수를 얻는다고 제시한다.

예시에서는 소프트맥스 이후 특정 후보가 거의 1.0의 확률을 갖는 것으로 나타난다. 이를 통해 저자는 문맥적으로 일관된 여러 증거가 하나의 어휘 후보에 누적되는 구조를 강조한다.

다만 이 결과는 실제 언어 모델의 예측 성능을 보여주는 것이 아니라, 저자가 설정한 단순화된 공기 행렬과 수치에 기반한 설명용 계산이다. 따라서 언어 일반화 능력이나 실제 문법·의미 이해 능력에 대한 실험적 증거로 해석할 수는 없다.

### 3.4 사영의 유일성 명제

논문은 다음 조건을 만족하는 선형 연산자가 \(QSQ^\top\)뿐이라고 주장한다.

\[
u^\top T(S)v
=
(Q^\top u)^\top S(Q^\top v)
\]

모든 \(u,v\)에 대해 이 등식이 성립하면,

\[
T(S)=QSQ^\top
\]

가 된다.

이 명제의 의미는 선택 행렬 \(Q\)가 정의하는 부분공간에서 원래의 쌍선형 구조를 보존하는 사영이 \(QSQ^\top\)로 결정된다는 것이다. 이는 제안한 연산의 선형대수적 일관성을 뒷받침한다.

그러나 이 증명은 사실상 조건 자체를 식으로 다시 쓰는 방식에 가깝다. 즉, 일반적인 자기 어텐션의 유일성을 증명했다기보다는, 특정한 내적 보존 조건을 부과했을 때 그 조건을 만족하는 행렬 표현이 \(QSQ^\top\)임을 확인한 것이다.

### 3.5 전체 트랜스포머와의 연결

논문이 제시하는 가장 중요한 이론적 성과는 다음과 같은 대응 관계다.

| 분포 의미론적 요소 | 트랜스포머 요소 |
|---|---|
| 전역 공기 행렬 \(S\) | 학습된 관계 구조 |
| \(QSQ^\top\) | 시퀀스 내부 문맥 점수 |
| 비대칭 행렬 \(W_QW_K^\top\) | 쿼리-키 적합도 |
| \(P\) | 위치 정보 |
| \(W_V\) | 값 표현의 변환 |
| 여러 사영 구조 | 다중 헤드 어텐션 |

이 대응은 트랜스포머를 고전적 분포 의미론의 단순한 대체물이 아니라, 이를 순서 민감하고 방향성 있으며 학습 가능한 형태로 확장한 모델로 보는 관점을 제공한다.

## 4. 연구의 시사점 및 한계점

### 4.1 연구의 주요 시사점

#### 첫째, 자기 어텐션에 대한 새로운 개념적 설명을 제공한다

본 논문은 자기 어텐션을 검색 시스템의 은유가 아니라 **전역 분포 구조를 현재 시퀀스에 맞게 사영하는 연산**으로 설명한다. 이는 어텐션 행렬이 단순히 유사도를 계산하는 것이 아니라, 문맥에 따라 전역 의미 구조를 재구성하는 역할을 한다는 관점을 제시한다.

#### 둘째, 쿼리-키 분리의 의미를 재해석한다

쿼리와 키의 분리는 데이터베이스 검색을 모방하기 위한 것이 아니라, 대칭적인 공기 통계를 방향성 있는 관계로 확장하기 위한 장치라는 설명을 제시한다. 이 관점은 주어-목적어, 행위자-대상, 원인-결과처럼 방향성을 갖는 언어 관계를 이해하는 데 유용하다.

#### 셋째, 위치 인코딩과 다중 헤드를 하나의 원리로 통합한다

위치 인코딩을 단순히 어텐션에 추가되는 보조 정보가 아니라, 사영의 입력 공간을 확장하는 과정으로 해석한다. 또한 다중 헤드는 여러 관계 구조를 병렬로 분해·학습하는 방식으로 설명한다. 이를 통해 트랜스포머 구성 요소들이 서로 무관한 설계 조각이 아니라 하나의 문맥 사영 원리를 정교화한 결과라는 통합적 관점을 제공한다.

#### 넷째, 분포 의미론과 신경망 모델 사이의 연결을 강화한다

GloVe, 행렬 인수분해, 공기 통계와 트랜스포머의 선형 사영을 하나의 연속선상에 놓는다. 이는 고전적인 분포 의미론이 현대 신경망 표현 학습과 단절된 것이 아니라, 더 유연하고 학습 가능한 형태로 확장되었다고 해석할 수 있게 한다.

#### 다섯째, 어텐션 연구를 위한 분석적 출발점을 제시한다

이 틀은 향후 다음과 같은 연구로 확장될 가능성이 있다.

- 공기 행렬에서 초기화된 어텐션의 학습 효과 분석
- 특정 어텐션 헤드와 구문·의미 관계의 대응 검증
- 위치 인코딩 방식별 사영 구조 비교
- 어텐션 행렬의 비대칭성과 언어적 방향성 측정
- 저랭크 관계 분해와 다중 헤드 전문화의 정량적 분석

### 4.2 이론적·수학적 한계

#### 1. \(QSQ^\top\)는 엄밀한 의미의 사영 연산자와 다르다

일반적으로 사영 행렬은 \(P^2=P\)와 같은 멱등성 조건을 만족하는 연산자를 의미한다. 그러나 \(QSQ^\top\)는 일반적인 공기 행렬 \(S\)에 대한 부분행렬 추출 또는 이중 선형 제한에 가깝고, 반드시 멱등적인 사영 행렬인 것은 아니다. 따라서 “사영”이라는 용어는 기하학적 정사영이라기보다 **부분공간으로의 제한 또는 투영된 관계 구조**라는 의미로 사용하는 것이 더 정확하다.

#### 2. 공기 행렬과 학습된 \(W_QW_K^\top\)의 동일시는 개념적이다

논문도 인정하듯이, 실제 트랜스포머가 학습한

\[
W_QW_K^\top
\]

가 특정 말뭉치 공기 행렬 \(S\)와 직접 동일하다는 증거는 제시되지 않는다. 두 구조가 모두 관계를 표현하는 행렬이라는 형식적 유사성은 있지만, 학습된 내부 표현은 다층 변환, 비선형성, 목적 함수, 토큰 위치, 문맥 길이 등의 영향을 받는다.

따라서 “트랜스포머가 공기 행렬을 학습한다”는 주장은 실증적으로 검증되어야 하며, 현재 논문에서는 해석적 비유 또는 구조적 대응에 머문다.

#### 3. 행 합 정규화와 소프트맥스의 차이가 크다

논문은 단순 정규화

\[
\frac{M_{rs}}{\sum_tM_{rt}}
\]

를 어텐션 가중치와 연결하지만, 실제 트랜스포머는 소프트맥스를 사용한다. 두 방식은 수학적 성질과 최적화 특성이 다르다.

- 단순 정규화는 음수 점수에 취약하다.
- 행 합이 0이면 정의되지 않는다.
- 점수 간 상대적 차이를 지수적으로 증폭하지 않는다.
- 표준 어텐션의 확률 분포와 동일한 온도·집중도 조절 특성을 갖지 않는다.

따라서 \(QSQ^\top\)에서 표준 어텐션이 “자연스럽게 도출된다”는 주장은 추가적인 가정이나 변환을 필요로 한다.

#### 4. 위치 인코딩 모델이 실제 트랜스포머와 직접 대응하지 않는다

논문은 \(Q'=Q+P\)를 사용해 위치 정보를 토큰 선택 행렬에 더한다. 그러나 실제 트랜스포머에서는 위치 임베딩을 토큰 표현에 더하거나, 회전 변환(RoPE), 상대 위치 바이어스, ALiBi 등 다양한 방식으로 결합한다. 특히 위치 정보가 반드시 원래 공기 행렬 \(S\)와 동일한 공간에 삽입된다고 보기는 어렵다.

또한 본문에서 제시한 블록 행렬 표현은 \((Q+P)S(Q+P)^\top\)의 일반적인 전개와 차원상 동일하지 않으므로, 이 부분은 엄밀한 행렬 구조로 재정식화될 필요가 있다.

#### 5. 다중 헤드를 공기 행렬의 저랭크 분해로 보는 것은 가설적이다

각 헤드가 서로 다른 관계 유형을 학습한다는 해석은 직관적으로 설득력이 있지만, 다중 헤드 어텐션이 실제로 하나의 \(S\)를 저랭크 성분 \(S^{(1)},\ldots,S^{(h)}\)로 분해한다는 것은 직접적으로 증명되지 않는다. 헤드 간에는 중복성, 상호작용, 비선형 후처리, 출력 사영이 존재하기 때문이다.

이 주장을 뒷받침하려면 헤드별 관계 행렬의 스펙트럼 분석, 헤드 간 독립성 측정, 실제 구문·의미 라벨과의 정량적 상관 분석이 필요하다.

### 4.3 경험적 한계

- 실제 데이터셋에 대한 실험이 없다.
- GloVe, BERT, GPT, Transformer-XL 등 실제 모델의 내부 가중치를 분석하지 않는다.
- 제안한 공기 사영과 표준 자기 어텐션 사이의 예측 성능을 비교하지 않는다.
- 다의성 해소, 문법성 판별, 다음 토큰 예측에 대한 정량적 지표가 없다.
- 예시에서 사용된 공기 행렬과 점수는 설명을 위해 구성된 것이므로 현실 언어의 통계적 복잡성을 반영하지 않는다.
- 본문 예시의 일부 수치와 정규화 결과는 재검산 및 산출 과정의 상세 공개가 필요하다.

### 4.4 종합 평가

이 논문의 가장 큰 기여는 새로운 트랜스포머 구조나 성능 향상 기법을 제안한 데 있지 않다. 핵심 기여는 자기 어텐션을 **분포 의미론, 행렬 사영, 비대칭 관계 학습, 위치 구조, 다중 헤드 분해를 잇는 통합적 해석 틀**로 제시한 데 있다.

다만 현재 결과는 주로 개념적·대수적 수준에 머물러 있다. 따라서 논문의 강한 표현인 “트랜스포머 아키텍처가 사영 원리에서 자연스럽게 귀결된다”는 주장을 확립하려면, 향후 실제 모델과 데이터에 대한 정량적 검증이 필요하다. 특히 공기 행렬과 학습된 어텐션 커널의 관계, 위치 인코딩의 사영 해석, 다중 헤드의 저랭크 분해 가설을 실험적으로 검증하는 것이 후속 연구의 핵심 과제가 될 것이다.
