# Improving Sample Quality of Diffusion Models Using Self-Attention Guidance 요약본

# 1. 연구 배경 및 목적

## 연구 배경

확산 모델(DDM)은 반복적인 잡음 제거 과정을 통해 높은 품질과 다양성을 갖춘 이미지를 생성한다. 특히 다음과 같은 유도(guidance) 기법이 성능 향상에 크게 기여해 왔다.

- **분류기 유도(CG)**: 별도로 학습된 분류기의 클래스 예측 gradient를 이용해 특정 클래스 방향으로 샘플을 이동시킨다.
- **분류기 없는 유도(CFG)**: 조건부 모델과 무조건부 모델의 예측 차이를 이용해 클래스 또는 텍스트 조건의 반영 강도를 조절한다.
- **텍스트·CLIP 유도**: 텍스트 프롬프트와 이미지 표현의 정렬을 강화한다.

그러나 기존 유도 방식은 공통적으로 외부 조건에 의존한다는 한계가 있다. CG는 별도 분류기 학습이 필요하고, CFG는 조건 제거 학습을 포함한 별도의 학습 설계가 요구된다. 따라서 레이블이나 텍스트 조건이 없는 비조건부 생성 모델에는 직접 적용하기 어렵다.

## 연구 목적

본 논문은 확산 모델이 생성 과정 중 내부적으로 형성하는 정보를 활용하여, 외부 레이블·텍스트·분류기·추가 미세 조정 없이 샘플 품질을 향상하는 방법을 제안한다.

핵심 목적은 다음과 같다.

1. 기존 조건부 유도 공식을 외부 조건이 없는 비조건부 설정까지 일반화한다.
2. 확산 모델 내부의 자체 어텐션 맵을 이용해 중요한 영역을 자동으로 식별한다.
3. 중요한 정보를 선택적으로 가린 뒤 원래 예측과 가려진 입력의 예측 차이를 이용해 역확산 과정을 유도한다.
4. ADM, IDDPM, Stable Diffusion, DiT 등 서로 다른 구조의 확산 모델에 적용 가능한 범용 샘플링 기법을 제시한다.
5. CG와 CFG 같은 기존 유도 방법과 결합하여 추가적인 성능 향상이 가능한지 검증한다.

논문의 중심 주장은 **확산 모델 자체가 생성 과정에서 중요하다고 판단한 내부 시각 정보를 다시 유도 신호로 활용할 수 있다**는 것이다.

# 2. 핵심 방법론 및 아키텍처

## 2.1 확산 유도의 일반화

기존 유도 방식은 외부 조건 \(c\)를 사용한다. 본 논문은 조건을 보다 일반적인 내부·외부 정보 \(h_t\)로 정의한다. 현재 시점의 샘플을 \(\mathbf{x}_t\), 일부 정보가 제거된 섭동 샘플을 \(\bar{\mathbf{x}}_t\)라고 하면, 유도된 잡음 예측은 다음과 같이 표현할 수 있다.

\[
\tilde{\epsilon}(\bar{\mathbf{x}}_t,h_t)
=
\epsilon_\theta(\bar{\mathbf{x}}_t,h_t)
+
s\left[
\epsilon_\theta(\bar{\mathbf{x}}_t,h_t)
-
\epsilon_\theta(\bar{\mathbf{x}}_t)
\right].
\]

여기서 \(s\)는 유도 강도이다. 이 식은 조건이 있는 입력과 조건이 제거된 입력에 대한 모델의 예측 차이를 증폭한다는 점에서 CFG와 유사하다. 다만 본 논문에서는 \(h_t\)가 반드시 클래스나 텍스트일 필요가 없다. 중간 샘플에 내재된 시각 정보도 조건으로 간주할 수 있다.

즉, 저자들은 유도를 다음과 같이 재해석한다.

> 중요한 정보를 의도적으로 제거한 입력과 원래 입력을 모델에 각각 통과시키고, 두 예측의 차이를 통해 제거된 정보가 더 잘 보존되는 방향으로 역과정을 수정한다.

## 2.2 블러 유도: SAG의 기본 형태

SAG에 앞서 저자들은 **블러 유도(blur guidance)**를 제안한다.

확산 모델은 현재 시점의 샘플 \(\mathbf{x}_t\)로부터 중간 복원 이미지 \(\hat{\mathbf{x}}_0\)를 추정한다.

\[
\hat{\mathbf{x}}_0
=
\frac{
\mathbf{x}_t-\sqrt{1-\bar{\alpha}_t}\epsilon_\theta(\mathbf{x}_t,t)
}{
\sqrt{\bar{\alpha}_t}
}.
\]

그 후 \(\hat{\mathbf{x}}_0\)에 가우시안 블러를 적용하여 세부 정보가 제거된 \(\tilde{\mathbf{x}}_0\)를 만들고, 동일한 잡음 수준으로 다시 변환한다.

\[
\tilde{\mathbf{x}}_t
=
\sqrt{\bar{\alpha}_t}\tilde{\mathbf{x}}_0
+
\sqrt{1-\bar{\alpha}_t}\epsilon_\theta(\mathbf{x}_t,t).
\]

블러 유도는 원래 입력 \(\mathbf{x}_t\)와 블러 처리된 입력 \(\tilde{\mathbf{x}}_t\)의 예측 차이를 활용한다. 이 방식은 미세한 세부 정보를 복원하도록 유도하지만, 전체 이미지를 블러 처리하기 때문에 유도 강도가 커지면 전역적인 구조가 지나치게 훼손되고 샘플에 잡음이 누적될 수 있다.

## 2.3 자체 어텐션 유도(SAG)

SAG는 블러 유도의 문제를 해결하기 위해 **전체 이미지가 아니라 확산 모델이 중요하다고 판단한 영역만 선택적으로 블러 처리**한다.

### 단계 1: 자체 어텐션 맵 추출

확산 모델 내부의 자체 어텐션 맵을 \(A_t^S\)라 한다. 여러 헤드와 공간 위치에 걸친 어텐션 맵에 전역 평균 풀링을 적용하고, 이를 원래 샘플 해상도로 업샘플링한다.

\[
A_t
=
\mathrm{Upsample}
\left(
\mathrm{Reshape}
\left(
\mathrm{GAP}(A_t^S)
\right)
\right).
\]

이렇게 얻은 \(A_t\)는 현재 확산 단계에서 모델이 집중하는 공간적 영역을 나타낸다.

### 단계 2: 중요 영역 마스킹

어텐션 맵의 평균값을 임계값 \(\psi\)로 사용해 중요 영역을 정의한다.

\[
M_t=\mathbf{1}(A_t>\psi).
\]

\(M_t=1\)인 영역은 모델이 상대적으로 높은 관심을 보이는 패치이다.

### 단계 3: 중요 영역만 블러 처리

중간 복원 \(\hat{\mathbf{x}}_0\)를 블러 처리한 뒤 동일한 잡음 수준으로 되돌린 \(\tilde{\mathbf{x}}_t\)를 만든다. 그리고 중요 영역에 대해서만 블러 처리된 값을 적용한다.

\[
\hat{\mathbf{x}}_t
=
(1-M_t)\odot\mathbf{x}_t
+
M_t\odot\tilde{\mathbf{x}}_t.
\]

따라서 \(\hat{\mathbf{x}}_t\)는 다음 특성을 가진다.

- 중요하다고 판단된 영역: 블러 처리되어 세부 정보가 제거됨
- 나머지 영역: 원래 입력의 구조와 정보가 그대로 유지됨

이 선택적 마스킹은 전역 블러보다 모델 입력의 분포를 덜 훼손하므로 높은 유도 강도에서도 안정적이다.

### 단계 4: 두 예측의 차이를 활용한 유도

원래 입력과 선택적으로 블러 처리된 입력을 각각 모델에 통과시켜 다음과 같이 유도된 잡음 예측을 계산한다.

\[
\tilde{\epsilon}(\mathbf{x}_t)
=
\epsilon_\theta(\hat{\mathbf{x}}_t)
+
(1+s)
\left[
\epsilon_\theta(\mathbf{x}_t)
-
\epsilon_\theta(\hat{\mathbf{x}}_t)
\right].
\]

이 식은 블러로 제거된 중요한 세부 정보가 원래 입력에 존재한다는 사실을 이용한다. 두 예측의 차이를 확대함으로써 모델이 해당 세부 정보를 더 충실히 복원하도록 유도한다.

## 2.4 전체 샘플링 구조

각 역확산 단계에서 SAG는 다음 순서로 실행된다.

1. 원래 샘플 \(\mathbf{x}_t\)에 대해 잡음 예측과 자체 어텐션 맵을 계산한다.
2. 어텐션 맵으로 중요 영역 마스크 \(M_t\)를 생성한다.
3. 현재 샘플에서 \(\hat{\mathbf{x}}_0\)를 추정한다.
4. \(\hat{\mathbf{x}}_0\)를 블러 처리하고 다시 현재 잡음 수준으로 변환한다.
5. 중요 영역에만 블러 결과를 삽입한다.
6. 수정된 샘플 \(\hat{\mathbf{x}}_t\)를 다시 모델에 입력한다.
7. 원래 예측과 수정된 입력의 예측 차이를 증폭한다.
8. 유도된 잡음 예측으로 \(\mathbf{x}_{t-1}\)를 샘플링한다.

SAG는 모델을 새로 학습하지 않고, 기존 확산 모델의 순전파 결과와 자체 어텐션을 샘플링 중에 활용한다는 점이 핵심이다.

## 2.5 기존 유도 방법과의 결합

SAG는 CG나 CFG를 대체하는 방식이 아니라 이들과 직교적인 추가 유도 신호로 작동한다.

CFG와 결합할 경우 효율적인 형태는 다음과 같다.

\[
\tilde{\epsilon}(\mathbf{x}_t)
=
\epsilon_\theta(\mathbf{x}_t,c)
+
s_c
\left[
\epsilon_\theta(\mathbf{x}_t,c)
-
\epsilon_\theta(\mathbf{x}_t)
\right]
+
s_s
\left[
\epsilon_\theta(\mathbf{x}_t)
-
\epsilon_\theta(\bar{\mathbf{x}}_t)
\right].
\]

첫 번째 차이 항은 텍스트 조건을 반영하고, 두 번째 차이 항은 자체 어텐션 기반의 내부 시각 정보를 반영한다. 따라서 **조건 정렬성은 CFG가, 세부 묘사와 아티팩트 억제는 SAG가 담당하는 구조**로 이해할 수 있다.

# 3. 주요 실험 성과

## 3.1 비조건부 생성에서의 성능 향상

SAG의 가장 중요한 장점은 클래스 레이블이나 텍스트 프롬프트가 없는 비조건부 모델에도 적용할 수 있다는 점이다.

### ADM, ImageNet 256×256

비조건부 ADM에서 50K 샘플을 평가한 결과는 다음과 같다.

| 지표 | SAG 없음 | SAG 적용 | 변화 |
|---|---:|---:|---:|
| FID | 26.21 | **20.08** | 6.13 개선 |
| sFID | 6.35 | **5.77** | 0.58 개선 |
| IS | 39.70 | **45.56** | 5.86 향상 |
| 정밀도 | 0.61 | **0.68** | 0.07 향상 |
| 재현율 | 0.63 | 0.59 | 0.04 하락 |

FID, sFID, IS, 정밀도가 모두 개선되었다. 이는 SAG가 샘플의 사실성, 세부 묘사, 분포 내 충실도를 높인다는 것을 보여준다. 반면 재현율은 하락했는데, 이는 품질과 다양성 사이의 전형적인 trade-off를 반영한다.

### 조건부 ADM

ImageNet 조건부 ADM에서도 FID가 다음과 같이 개선되었다.

- SAG 없음: FID **10.94**
- SAG 적용: FID **9.41**

IS 역시 100.98에서 104.79로 향상되었다. 따라서 SAG의 효과는 비조건부 모델에만 국한되지 않고 조건부 모델에서도 유지된다.

### LSUN Cat 및 Horse

비조건부 LSUN 모델에서도 소폭이지만 일관된 개선이 관찰되었다.

- LSUN Cat: FID **7.03 → 6.87**
- LSUN Horse: FID **3.45 → 3.43**

데이터셋에 따라 향상 폭은 달랐지만, SAG가 ImageNet 이외의 데이터 분포에도 적용 가능함을 확인했다.

## 3.2 다른 확산 모델로의 일반화

### IDDPM

ImageNet 64×64 비조건부 IDDPM에서:

- FID **19.2 → 18.0**

ADM뿐 아니라 개선된 분산 예측 구조를 사용하는 IDDPM에서도 성능 향상이 나타났다.

### Stable Diffusion

Stable Diffusion에서는 빈 프롬프트를 사용한 실험을 통해 외부 텍스트 조건 없이도 SAG가 샘플 품질을 개선하는지 평가했다.

동일한 무작위 시드로 비교한 인간 평가에서 SAG 적용 샘플이 더 높은 시각적 품질과 현실성을 가진 것으로 평가되었다. 정성적으로는 다음과 같은 개선이 관찰되었다.

- 물체의 세부 묘사 강화
- 윤곽과 질감의 선명도 향상
- 생성 과정에서 발생하는 일부 아티팩트 감소
- 전반적인 시각적 현실성 향상

이는 SAG가 클래스 조건뿐만 아니라 텍스트 조건이 없는 잠재 확산 모델에도 적용될 수 있음을 보여준다.

### DiT

ImageNet 256×256으로 학습된 DiT-XL/2에서 CFG와 SAG를 결합한 결과:

- CFG만 사용: FID **2.27**
- CFG + SAG: FID **2.16**

향상 폭은 크지 않지만, 이미 강력한 CFG 기반 모델에서도 SAG가 추가적인 이득을 제공한다.

## 3.3 기존 유도법과의 결합 성능

ImageNet 128×128 ADM에서 CG와 SAG를 각각 또는 함께 적용했다.

| 설정 | FID | sFID | 정밀도 |
|---|---:|---:|---:|
| 유도 없음 | 5.91 | 5.09 | 0.70 |
| CG만 | 2.97 | 5.09 | 0.78 |
| SAG만 | 5.11 | **4.09** | 0.72 |
| CG + SAG | **2.58** | 4.35 | **0.79** |

CG와 SAG를 함께 사용하면 CG만 사용할 때보다:

- FID: **2.97 → 2.58**
- 정밀도: **0.78 → 0.79**

로 개선되었다. 이는 두 방법이 동일한 신호를 중복적으로 사용하는 것이 아니라, 서로 다른 정보를 이용한다는 근거이다.

- CG: 외부 클래스 조건에 맞는 방향으로 유도
- SAG: 내부 자체 어텐션이 포착한 세부·구조 정보 보존

## 3.4 마스킹 전략에 대한 절제 연구

ImageNet 128×128 ADM에서 여러 마스킹 전략을 비교한 결과:

| 마스킹 방식 | FID | IS |
|---|---:|---:|
| 기준선 | 5.98 | 141.72 |
| 전역 블러 | 5.82 | 143.15 |
| 고주파 영역 | 5.74 | 148.87 |
| 무작위 영역 | 5.68 | 148.99 |
| 정사각형 영역 | 5.68 | 146.50 |
| DINO 어텐션 | 5.63 | 146.18 |
| **확산 모델 자체 어텐션** | **5.47** | **151.12** |

SAG가 가장 높은 성능을 보였다. 이는 단순히 일부 영역을 블러 처리하는 것보다, **현재 확산 모델이 해당 생성 단계에서 중요하다고 판단하는 영역을 사용하는 것이 효과적**이라는 것을 의미한다.

또한 DINO와 같은 외부 자기지도 모델의 어텐션보다 확산 모델 자체 어텐션이 우수했다. 이는 생성 모델의 어텐션이 일반적인 의미 객체뿐 아니라 생성에 필요한 고주파 세부 정보까지 포착하기 때문으로 해석된다.

## 3.5 블러 세기와 유도 강도

가우시안 블러의 표준편차 \(\sigma\)에 대한 실험에서는 중간 정도의 블러가 가장 효과적이었다.

| 설정 | FID | IS |
|---|---:|---:|
| \(\sigma \to 0\), 사실상 블러 없음 | 5.98 | 141.72 |
| \(\sigma=1\) | 5.58 | 145.85 |
| **\(\sigma=3\)** | **5.47** | **151.12** |
| \(\sigma=9\) | 5.70 | 148.70 |
| \(\sigma=27\) | 5.80 | 147.83 |
| 평균 픽셀 | 5.84 | 147.52 |

너무 약한 블러는 정보 제거 효과가 부족하고, 너무 강한 블러는 입력을 데이터 분포에서 벗어나게 만들 수 있다. 따라서 데이터 해상도와 모델에 맞는 적절한 \(\sigma\) 선택이 중요하다.

유도 강도 역시 적정 범위가 존재했다. 실험에서는 대체로 \(s=0.1\) 부근에서 FID, sFID, IS가 가장 좋았으며, 지나치게 큰 유도 강도에서는 오히려 품질이 악화되었다.

## 3.6 계산 비용

| 방법 | GPU 메모리 | 실행 시간 |
|---|---:|---:|
| 유도 없음 | 12,167 MB | 108.27초 |
| SAG | 12,209 MB | 186.60초 |
| CFG | 12,218 MB | 190.27초 |

SAG는 추가 순전파 때문에 유도하지 않는 샘플링보다 실행 시간이 약 1.7배 증가한다. 그러나 메모리 사용량은 거의 증가하지 않으며, 실행 시간과 메모리 측면에서 CFG와 유사하다.

# 4. 연구의 시사점 및 한계점

## 4.1 연구의 시사점

### 1) 유도의 개념을 외부 조건에서 내부 정보로 확장

기존 유도는 클래스, 텍스트, 분류기 등 외부 정보가 있어야 한다는 전제가 강했다. 본 논문은 유도에 필요한 조건이 반드시 외부 정보일 필요는 없으며, 확산 모델의 중간 표현과 어텐션도 유도 신호가 될 수 있음을 보였다.

이는 유도 방법을 다음과 같이 확장한다.

- 레이블이 없는 데이터셋
- 비조건부 확산 모델
- 빈 프롬프트를 사용하는 텍스트-이미지 모델
- 추가 분류기나 재학습이 어려운 사전 학습 모델

에 적용할 수 있다.

### 2) 모델 내부의 어텐션을 생성 제어 신호로 활용

SAG는 자체 어텐션을 단순한 특징 추출 도구가 아니라, 샘플링 과정의 입력을 변형하고 예측을 수정하는 제어 장치로 사용한다. 특히 어텐션이 높은 영역이 최종 이미지의 고주파 세부 정보 및 전경 객체와 관련된다는 분석은 다음을 시사한다.

- 확산 모델의 어텐션은 생성에 중요한 공간 정보를 내포한다.
- 어텐션 맵은 샘플링 단계별로 동적인 중요도 지도를 제공한다.
- 생성 모델 내부 표현을 별도의 보조 네트워크 없이 활용할 수 있다.

### 3) 품질 향상과 조건 정렬을 분리할 수 있음

CFG나 CG는 주로 클래스·텍스트 조건에 대한 정렬성을 강화한다. 반면 SAG는 조건과 독립적으로 이미지의 세부 묘사와 구조적 완성도를 보완한다. 두 방법이 결합될 수 있다는 결과는 확산 유도가 하나의 단일 신호가 아니라 여러 종류의 보정 신호로 분해될 수 있음을 보여준다.

### 4) 사전 학습 모델에 대한 플러그인 방식 적용

SAG는 모델 파라미터를 수정하지 않고 샘플링 알고리즘에 추가된다. 따라서 새로운 학습 데이터나 미세 조정 없이 다양한 확산 백본에 적용할 수 있다. 이 점은 기존 모델을 재학습하기 어려운 실제 서비스나 연구 환경에서 실용적이다.

### 5) 품질·다양성 조절 가능성

재현율 감소는 SAG가 모든 가능한 샘플을 폭넓게 생성하기보다, 모델이 중요하게 판단한 세부 정보와 고충실도 영역을 더 강하게 복원한다는 점을 보여준다. 따라서 SAG 강도 \(s\)를 조절하여 다음과 같은 품질–다양성 균형을 선택할 수 있다.

- 낮은 강도: 원래 샘플링 다양성 유지
- 중간 강도: 세부 묘사와 사실성 향상
- 높은 강도: 정밀도는 증가할 수 있으나 다양성 저하 및 잡음 발생 가능

## 4.2 한계점

### 1) 추가 순전파로 인한 샘플링 비용 증가

SAG는 원래 입력과 마스킹된 입력에 대해 모델을 추가로 실행해야 한다. 이에 따라 실행 시간이 유도하지 않는 경우보다 크게 증가한다.

- 유도 없음: 108.27초
- SAG: 186.60초

따라서 고해상도 이미지나 대규모 배치 샘플링에서는 비용이 중요한 문제가 될 수 있다. 저자들은 향후 유도된 확산 모델을 단일 모델로 증류하는 방법을 가능한 해결책으로 제시한다.

### 2) 하이퍼파라미터 의존성

SAG의 성능은 다음 요소에 영향을 받는다.

- 유도 강도 \(s\)
- 블러 세기 \(\sigma\)
- 어텐션 마스킹 임계값 \(\psi\)
- 어텐션을 추출하는 계층
- 입력 해상도와 모델 구조

예를 들어 지나치게 높은 유도 강도에서는 샘플 품질이 저하되고, 블러가 너무 강하면 구조적 모호성과 잡음이 발생한다. 따라서 모델과 해상도별로 적절한 설정을 찾는 과정이 필요하다.

### 3) 다양성과 참신성 감소 가능성

정밀도와 FID는 향상되지만 재현율이 낮아지는 현상이 관찰되었다. 이는 SAG가 생성 결과를 더 현실적이고 선명하게 만들지만, 동시에 샘플 공간을 좁힐 수 있음을 의미한다.

특히 다음과 같은 상황에서는 문제가 될 수 있다.

- 희귀한 형태나 비전형적 구성을 생성해야 하는 경우
- 창의성과 다양성이 중요한 창작 응용
- 넓은 데이터 분포를 빠짐없이 커버해야 하는 경우

### 4) 자체 어텐션이 항상 의미 있는 중요도를 제공한다고 보장하기 어려움

본 논문에서는 확산 모델의 자체 어텐션이 고주파 세부 정보와 전경 객체를 잘 포착한다는 것을 보였지만, 모든 모델·모든 시점·모든 도메인에서 동일하게 작동한다고 보장할 수는 없다.

특히:

- 자체 어텐션이 없는 확산 모델
- 어텐션 구조가 다른 모델
- 비전 이미지와 다른 도메인의 생성 모델
- 매우 높은 잡음 단계에서 어텐션이 불안정한 경우

에는 SAG의 효과가 달라질 수 있다.

### 5) 이산 확산 모델에 대한 검증 부족

저자들은 토큰 확률을 직접 모델링하는 이산 확산 모델에 SAG가 더 적합할 가능성을 제시하지만, 본 연구의 실험은 주로 연속 이미지 확산 모델을 대상으로 한다. 텍스트 토큰이나 벡터 양자화 잠재 공간에 SAG를 어떻게 정의할지는 후속 연구가 필요하다.

### 6) 평가 범위와 인간 평가의 제한성

실험은 ImageNet, LSUN, Stable Diffusion, DiT 등 다양한 모델을 포함하지만, 주된 정량 평가는 이미지 생성 품질 지표에 집중되어 있다. FID와 IS는 전반적 분포 품질을 평가하지만 다음을 충분히 반영하지 못할 수 있다.

- 텍스트 조건과의 정확한 의미 정렬
- 장면 구성의 논리성
- 인간의 미적 선호
- 희귀한 프롬프트와 복잡한 조합에 대한 일반화

Stable Diffusion 인간 평가도 500쌍, 50명 참가자 기반의 비교 평가이므로, 더 다양한 프롬프트·도메인·사용자 집단을 포함한 검증이 필요하다.

## 종합 평가

이 논문은 확산 모델의 샘플링 단계에서 이미 존재하는 자체 어텐션과 중간 복원 정보를 활용해, **추가 학습이나 외부 조건 없이 생성 품질을 높이는 간단한 플러그인형 유도 기법**을 제시했다는 점에서 의미가 크다. SAG의 핵심 강점은 중요한 영역을 선택적으로 블러 처리함으로써 블러 유도의 불안정성을 줄이고, CFG·CG와 결합 가능한 보완적 유도 신호를 제공한다는 것이다.

다만 SAG는 추가 순전파 비용, 하이퍼파라미터 의존성, 다양성 감소 가능성을 가진다. 따라서 실제 활용에서는 최고 품질만을 목표로 하기보다 유도 강도를 조절하여 **품질·다양성·계산 비용 사이의 균형을 선택하는 방식**이 적절하다.
